# Капибара

Редизайн сайта выездной химчистки мебели по дизайн-системе Airo.

**Сайт:** https://sokol040201.github.io/kapibara/

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Деплой на GitHub Pages

```bash
npm run deploy
```

Сборка уходит в ветку `gh-pages` с `basePath=/kapibara`.

## Страницы

- `/` — главная
- `/pervichnaya` — разовая чистка
- `/abonement` — абонемент и калькулятор модулей
- `/otzyvy` — отзывы 2ГИС
- `/politika` — политика конфиденциальности

Маскот: `public/mascot/`. Стиль: `design-system.md`.
